# Changelog

## 0.3.0 — 2026-10-07

First published Sprinter Playground release.

- Four visual journeys: liquidity provision, collateral-backed borrowing, card spending, and cross-chain operator liquidity.
- Adjustable example amounts, guided stages, and clearly labeled simulated outcomes.
- Separate live Credit workspace with account inspection, protocol discovery, and V2 lock/draw/repay/unlock transaction previews.
- Sequential wallet execution with chain/account checks, successful-receipt gating, and visible partial failures.
- GitHub Pages deployment with validation before publishing.
- Reproducible dependency setup, CI, 32 regression tests, and repository audit documentation.
- Removed obsolete aggregation code, Create React App scaffolding, and accidentally committed dependencies.

Liquidity deposits, card payments, and operator fills remain illustrative. Live funded-wallet transactions have not been exercised during verification.
